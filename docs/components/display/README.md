# Display

| Component | What it is |
| --- | --- |
| [Avatar](avatar.md) | An image with an initials fallback. |
| [Meter](meter.md) | A measured value within a known range. |
| [Separator](separator.md) | A horizontal or vertical divider. |
| [Scroll area](scroll-area.md) | A scroll container with a pixel scrollbar. |
| [Collapsible](collapsible.md) | A button that shows and hides a panel. |
| [Badge](badge.md) | Small status labels, styled with the px-badge class. |
