# Forms

| Component | What it is |
| --- | --- |
| [Checkbox](checkbox.md) | A labelled checkbox. The whole row is clickable. |
| [Checkbox group](checkbox-group.md) | A labelled list of checkboxes that share one array value. |
| [Switch](switch.md) | An on/off switch with a visible label. |
| [Radio group](radio-group.md) | A controlled radio group with a visible group label. |
| [Select](select.md) | A dropdown select with full keyboard support. |
| [Combobox](combobox.md) | A searchable single-select with a clear button. |
| [Autocomplete](autocomplete.md) | A free-text input with suggestions. |
| [Slider](slider.md) | A single-value slider with a live value label. |
| [Range slider](range-slider.md) | A two-thumb slider for a range of money. |
| [Number field](number-field.md) | A number input with minus and plus buttons. |
| [OTP field](otp-field.md) | A one-time-code input with one box per digit. |
| [Fieldset](fieldset.md) | Groups related fields under a legend. |
| [Input](input.md) | Text inputs styled with the px-input class. |
