# Overlays

All overlays render in a portal, trap or return focus as needed, and close with <kbd>Esc</kbd>. Base UI handles that behavior.

| Component | What it is |
| --- | --- |
| [Modal](modal.md) | A controlled dialog with a title, description and close button. |
| [Alert dialog](alert-dialog.md) | A confirmation dialog for destructive actions. |
| [Drawer](drawer.md) | A side panel that slides in from the right. |
| [Popover](popover.md) | A small panel attached to a trigger button. |
| [Preview card](preview-card.md) | A link that shows a preview card on hover or focus. |
| [Tooltip](tooltip.md) | An icon button with a tooltip. |
| [Toast](toast.md) | A button that shows a toast notification. |
