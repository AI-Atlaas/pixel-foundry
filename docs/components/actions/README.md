# Actions

| Component | What it is |
| --- | --- |
| [Button](button.md) | A button with a pixel border and a hard shadow. |
| [Toggle](toggle.md) | A single on/off button for actions like save or follow. |
| [Toggle group](toggle-group.md) | A row of toggle buttons for quick filters. |
| [Toolbar](toolbar.md) | A row of icon buttons with arrow-key navigation. |
